# Code of conduct

Be technical, be direct, be kind.

Unacceptable behaviour: personal attacks, harassment, discriminatory language,
deliberate disruption of discussions, publishing private information.

Maintainers may edit, remove or reject contributions and comments that break this
rule, and will explain why.

Report concerns to the maintainer listed in `plugin.yml` (`author: yanianz`) via
a GitHub issue marked **private** or a security advisory.
